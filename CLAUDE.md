# CLAUDE.md

Read [AGENTS.md](AGENTS.md) before editing or running anything in this
repository. It is binding, and it is the whole map: the conventions that are
enforced (commit identity, docs and tests in the same commit, versioning), the
operational cautions for a live account, the deliberate designs that must not
be "simplified", the settled dead ends that must not be reopened, the
measurement discipline, and the working loop from orientation to live
verification.

Deployment-specific facts (hosts, paths, camera ids, watchers, credentials)
are deliberately absent from this repository; they live with the operator.
Never write them into a tracked file.
